# Aftermovie: עוזר עריכה ל-DaVinci Resolve Studio (Mac)

הכלי מנתח את הקליפים מהמסיבה, מוצא את הרגעים הכי חזקים ובונה לך **טיימליינים חדשים** ב-Resolve:

| טיימליין חדש | מה יש בו |
|---|---|
| **AM Rough Cut v1** | ראף קאט של כ-3 דקות: Intro (כחול), Build (צהוב), Peak (כתום), Outro (סגול), עם מרקר בתחילת כל חלק |
| **AM Highlights Stringout v1** | 150 הרגעים הכי טובים, מהטוב ביותר ומטה, כל אחד עם מרקר של דירוג וציון |

## בטיחות
- **שום דבר לא נמחק ושום דבר קיים לא משתנה.** הסקריפטים רק קוראים את הטיימליין והקבצים, ויוצרים טיימליינים חדשים.
- אם כבר קיים טיימליין בשם הזה, ייווצר v2, v3 וכן הלאה.
- בכל זאת, ליתר ביטחון: לפני הריצה הראשונה עשה File > Export Project ושמור קובץ ‎.drp.

## התקנה (פעם אחת)
```bash
brew install ffmpeg
pip3 install numpy
```
ב-Resolve: **Preferences > System > General > External scripting using = Local**. אחר כך הפעל מחדש את Resolve.

## שימוש
1. פתח ב-Resolve את טיימליין ה-Selects (זה עם 199 הקליפים).
2. בטרמינל, מתוך התיקייה `aftermovie`:
```bash
./aftermovie.sh all
```
זה מריץ 3 שלבים:
1. **export**: קורא את הטיימליין הפתוח (קריאה בלבד).
2. **analyze**: מנתח תנועה, עוצמת סאונד, חדות ותאורה. לוקח בערך 10–30 דקות על 58 דקות חומר.
3. **build**: יוצר את הטיימליינים החדשים.

הקבצים נשמרים ב-`~/Desktop/Aftermovie/`. שם יש גם את `highlights.csv`: רשימת הרגעים הכי טובים עם טיים-קוד מקור, שאפשר לפתוח באקסל.

### אפשרויות
```bash
./aftermovie.sh analyze --length 150     # ראף קאט של 2:30 במקום 3:00
./aftermovie.sh analyze --stringout 250  # יותר רגעים בסטרינגאאוט
./aftermovie.sh analyze --folder "/Volumes/SSD/Party"  # לנתח את כל 6 השעות ולא רק את הטיימליין
./aftermovie.sh build                    # לבנות שוב (ייצור v2)
AFTERMOVIE_VIDEO_ONLY=1 ./aftermovie.sh build   # בלי אודיו מהשטח
```

### אפשרות נוספת: מתוך התפריט של Resolve
```bash
./install_menu_scripts.sh
```
אחרי זה הסקריפטים יופיעו ב-Workspace > Scripts > Aftermovie. את שלב הניתוח (analyze) עדיין מריצים בטרמינל.

## איך הציון עובד
- **Energy:** תנועה בפריים וכמה רועש בחדר. ריקודים, ידיים באוויר וצעקות מקבלים ציון גבוה.
- **Quality:** חדות ותאורה. שוטים מטושטשים, שחורים או שרופים יורדים בציון.
- **Peak** = הרבה אנרגיה. **Mood** = שוט יפה ורגוע, מתאים לפתיחה. **Build** = באמצע.
- בתוך כל חלק הקליפים מסודרים לפי סדר הערב, ושום רגע לא מופיע פעמיים.

## אחרי שתבחר שירים
אורכי הקליפים עכשיו הם זמניים: 3 שניות ב-Intro ושנייה אחת ב-Peak. כשיהיו שירים, השלב הבא הוא סקריפט שמזהה ביטים ודרופים בשיר ומיישר את החיתוכים לקצב.
